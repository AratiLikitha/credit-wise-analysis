# CreditWise - Loan Approval Prediction

Predicts loan approval status using customer data.

## Dataset
Loan data with income, credit history, loan amount, etc.

## Models Used
- KNN
- Logistic Regression
- Naive Bayes

## Steps Done
- Data Cleaning
- EDA with Matplotlib, Seaborn
- Feature Engineering
- Model Training & Evaluation (Accuracy, Precision, Recall, F1)

## Tech Stack
Python, Pandas, NumPy, Scikit-Learn, Anaconda, Jupyter Notebook
